데이터 분석 프로젝트

내가 고른 데이터로 문제 정의부터 모델 평가까지, 데이터 과학의 전 과정을 이 페이지 하나에서 직접 진행해 봅니다. 회귀·군집·연관분석을 오가며 실제 계산이 브라우저 안에서 그대로 실행됩니다.

문제 정의
데이터 수집
회귀 · 군집 · 연관분석

학습 목표

  • 문제 정의부터 데이터 수집·전처리·탐색·모델링·평가까지 데이터 과학의 전체 과정을 직접 수행할 수 있다.
  • 내 데이터의 특성에 맞는 분석 방법(회귀 또는 군집)을 선택하고, 그 결과를 해석할 수 있다.

기본 예시 데이터는 Ⅲ-3단원의 Mall_Customers.csv(쇼핑몰 고객 200명)입니다. 내 CSV 파일로 바로 바꿔서 진행할 수도 있습니다.

          알고 가기
          
데이터 프로파일링의 메뉴 설명

          

            
Overview데이터 프레임의 열의 개수, 데이터 타입, 결측치 비율 등 기본 정보를 제공한다.

            
Variables각 열에 대한 통계 정보(최솟값·최댓값·중앙값·평균값·표준편차 등)와 변수의 고윳값 개수, 결측치 개수·비율을 보여 준다.

            
Interactions변수 간의 상호 영향을 산점도로 보여 준다.

            
Correlations변수 간의 상관계수 행렬과 히트맵을 제공한다.

            
Missing Values변수별 결측치 비율과 패턴을 보여 준다.

            
Sample데이터 프레임의 상위 10개, 하위 10개 데이터를 보여 준다.

          k는 왜 사람이 직접 정하나요? ▾
          
k(군집 개수)는 k-평균 알고리즘의 하이퍼파라미터예요 — 모델이 스스로 찾는 값이 아니라 사람이 직접 정해야 합니다. k가 너무 작으면 성질이 다른 데이터가 한 군집에 뭉뚱그려지고, 너무 크면 의미 없이 잘게 쪼개져요. 그래서 몇 가지 k를 실제로 실행해 보고 실루엣 점수를 비교해서 정하는 것이 좋습니다.

        

        
        

      


      

        
연관분석은 어떻게 진행되나요?

        
수치형 열은 자동으로 하위 · 중위 · 상위 3구간으로 나누고, 범주형 열은 그대로 사용해서 "함께 자주 나타나는 특성"의 규칙을 찾습니다. (최소 지지도 10%, 최소 신뢰도 60%)

      


      

        
독립변수(X) / 종속변수(y)

        
종속변수(y)로 고른 열을 제외한 모든 수치형 열이 자동으로 독립변수(X)가 됩니다.
